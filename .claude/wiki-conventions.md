# Wiki Conventions — ShipFrame

Language: English.

## Categories

- `architecture` — system-level structure and decisions.
- `modules` — individual skills, agents, installers, and templates.
- `flows` — workflow routing and lifecycle behavior.
- `integrations` — external tools such as GitHub, ClickUp, Codex, Claude Code, and OpenCode.
- `configuration` — installation, metadata, and project profile settings.
