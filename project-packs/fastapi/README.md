# FastAPI Project Pack

Generic release and review notes for FastAPI repositories.

- Identify Python/runtime and dependency manager, ASGI server, app factory, routers, dependency injection, and Pydantic version.
- Check request/response schemas, validation, auth dependencies, exception handlers, OpenAPI compatibility, and async boundaries.
- Inspect lifespan hooks, database migrations, background tasks, and external integrations before release.
- Run project-defined formatter/linter, type checker, tests, and build/package checks; smoke health and changed routes under the intended ASGI server.
- Treat TestClient coverage separately from deployed/provider behavior.
