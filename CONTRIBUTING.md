# Contributing to ShipFrame

Thanks for helping improve ShipFrame. Before proposing a change:

1. Open an issue for substantial changes so scope and compatibility can be discussed.
2. Keep the generic core team-friendly; project-specific behavior belongs in opt-in profiles or packs.
3. Update affected documentation and tests with behavior or workflow changes.
4. Run the relevant checks from [AGENTS.md](AGENTS.md), and include their results in a pull request.
5. Open a draft pull request when the work is not ready for final review; explain scope, verification, and any remaining gaps.

Please do not include credentials, private tokens, or customer data in issues or pull requests.
